# نظام محاكاة كود نيمز نجد — الجيل الثاني

ذكاء اصطناعي يلعب اللعبة مع نفسه ويقيس: **هل الكلمات قابلة للربط؟
وهل اللعبة ممتعة فعلاً؟**

## التشغيل

```bash
node عميق.js 1500    # الاختبار العميق: ١٥٠٠ مباراة + تحليل كامل
node عزل.js          # قابلية الربط لكل كلمة من الـ٩٦٩
node final.js        # تقرير الجيل الأول (للمقارنة التاريخية)
```

## الجيل الثاني: ما الجديد؟

الجيل الأول كان يربط الكلمات **بالتصنيف فقط**: «طيور»، «أثاث». هذا
تفكير داخل الصندوق، ولا يشبه ما يفعله الإنسان.

الجيل الثاني يربط عبر **١٣ محوراً**:

| المحور | مثال |
|---|---|
| لون | ليمون + شمس + ذهب + عسل = «أصفر» |
| شكل | عجلة + سوار + رمان = «دائري» |
| خاصية | بركان + زلزال = «خطر» |
| صوت | ربابة + ناي + دف = «موسيقي» |
| مادة | حديد + زئبق + فلز = «معدن» |
| وظيفة | قمر + شعاع + مصباح = «ينير» |
| مكان | نجم + كوكب + مذنب = «سماء» |
| مجاز | ثعلب = «دهاء» · جمل = «صبر» |
| تراث | صحراء + بخور + عود = «بادية» |
| جزء | زجاج + عجلة + محرك = «سيارة» |
| تلازم | ملح ↔ فلفل |
| جذر | كتاب/مكتبة/كاتب |
| فئة | التصنيف التقليدي |

**٢٤٥ مفهوماً قابلاً للتلميح** بدل ٧٢.

## الملفات

| الملف | المحتوى |
|---|---|
| `kb.js` | قاعدة المعرفة: ١٠ محاور، ٧٤ مجموعة، ٩٠٣ مدخل، ٧١ زوج، ٣٠ جذر |
| `mind2.js` | بناء شبكة الربط + الذهن الفردي (إبداع/عمى/تفاوت) |
| `agents.js` | الكاتب (يوازن التغطية بالخطر) والمتوقّع |
| `match.js` | محرّك المباراة بقواعد كود نيمز الحقيقية |
| `board.js` | يستخرج `buildLinkableBoard` من ملف اللعبة نفسه |
| `عميق.js` | الاختبار العميق والتقرير |
| `عزل.js` | قابلية الربط لكل كلمة |
| `brain.js` `players.js` `engine.js` `run.js` `final.js` | الجيل الأول (محفوظ) |

## لماذا يُصدَّق

- **لا يغشّ:** اللاعب لا يقرأ `WORD_TOPIC_CUTS` من اللعبة، بل يعتمد
  معرفة مستقلة كُتبت يدوياً.
- **أذهان مختلفة:** الكاتب والمتوقّع ذهنان منفصلان. لكلٍّ عمى جزئي عن
  بعض الروابط، وتفاوت في تقدير قوّتها، وميل شخصي لمحاور معيّنة.
  لو تشاركا ذهناً واحداً لبلغت الدقة ٩٨٪ وهو رقم لا يحدث بين بشر.
- **قاعدة الإلزام:** الفريق ملزم بتخمين واحد على الأقل بعد كل تلميح،
  كما في اللعبة الحقيقية. بدون هذه القاعدة كانت المباريات تمتد ٣٨ دوراً.
- **تدرّج المهارة يعمل:** مبتدئ ٦٦٪ ← خبير ٨٧٪. لو لم يفرّق النموذج
  بين المستويات لكان معطّلاً.
