# نظام محاكاة كود نيمز نجد

أربعة لاعبين آليين يلعبون مباريات كاملة بقواعد اللعبة الحقيقية، على
اللوحة التي يبنيها `كود نيمز.html` نفسه.

## التشغيل

```bash
node final.js     # تقرير 100 مباراة + مقارنة بالنظام القديم
node verify.js    # مقارنة إعدادات TEAM_BUNDLES المختلفة
```

## الملفات

| الملف | المحتوى |
|---|---|
| `brain.js` | ٧٢ مفهوماً عربياً + شبكة الجوار الدلالي (تغطية ١٠٠٪) |
| `players.js` | الكاتب والمتوقّع، ولكل لاعب ذهن مستقل |
| `engine.js` | محرّك المباراة بقواعد اللعبة |
| `run.js` | يستخرج `buildLinkableBoard` من ملف اللعبة ويشغّله |
| `final.js` | تقرير الـ١٠٠ مباراة |
| `verify.js` | قياس أثر تغيير حجم الحزم |
| `words.json` | نسخة من قائمة الكلمات (٩٦٩) |

## لماذا يُصدَّق

- **معرفة مستقلة:** اللاعب لا يقرأ `WORD_TOPIC_CUTS` — لو فعل لغشّ.
- **أذهان مختلفة:** لو تشارك الكاتب والمتوقّع ذهناً واحداً لبلغت
  الدقة ٩٨٪، وهو رقم لا يحدث بين بشر.
- **عمى الكاتب:** لا يستحضر ٣٤٪ من الروابط، فيظن تلميحه آمناً بينما
  يرى فيه المتوقّع بطاقة أخرى — وهذا مصدر الخطأ الحقيقي في كود نيمز.
- **معايرة على بحث محكّم** (arXiv 2412.11373): الأدوار والكلمة السوداء
  وتوازن الفوز كلها ضمن نطاق المرجع.

## حدّ معروف

دقة ٩٤٪ أعلى من البشر (٦٠–٧٥٪) لأن الذهنين مبنيان على قاموس مرجعي
واحد. اقرأها كمقياس **مقارنة** بين نظامي اللوحة، لا كتوقّع لأداء بشري.
